# Codeforces Solutions

My solutions to Codeforces problems, written in Python 3.

## Solutions

| Problem | Name | Solution | Key idea |
|---------|------|----------|----------|
| [1A](https://codeforces.com/problemset/problem/1/A) | Theatre Square | [1A.py](1A.py) | Ceiling division per side: `(n+a-1)//a` |
| [4A](https://codeforces.com/problemset/problem/4/A) | Watermelon | [4A.py](4A.py) | Even and greater than 2 |
| [50A](https://codeforces.com/problemset/problem/50/A) | Domino piling | [50A.py](50A.py) | `m*n // 2` |
| [546A](https://codeforces.com/problemset/problem/546/A) | Soldier and Bananas | [546A.py](546A.py) | Arithmetic series sum `k*w*(w+1)/2`, minus money held |
| [617A](https://codeforces.com/problemset/problem/617/A) | Elephant | [617A.py](617A.py) | Ceiling division by 5 |
| [959A](https://codeforces.com/problemset/problem/959/A) | Mahmoud and Ehab and the even-odd game | [959A.py](959A.py) | Parity of `n` decides the winner |

## Running

Each solution reads from standard input:

```sh
python 1A.py < input.txt
```
